Vibe-Trading

开源金融研究 Agent · 多 Agent 协作团队
Wiki： vibetrading.wiki | GitHub： HKUDS/Vibe-Trading | PyPI： vibe-trading-ai
概述。 Vibe-Trading 将自然语言市场问题转化为可执行研究：路由技能与数据源、接入实时行情或券商流水、运行回测与因子分析，并输出带证据链、指标与风险提示的可复现 run card。我的实践重点是编排预设 swarm 团队、设计 Agent harness 工作流，并将该金融 Agent 栈与更广泛的 Agent 工具链研究（Cursor、Codex、Hermes Agent）打通。

研究闭环

路由 → grounding
  • 从用户 prompt 选择技能、数据源、工具与 swarm 团队
  • 运行时拉取股票、 crypto、期货、外汇、文档、URL 或券商流水
测试 → 交付
  • 回测、因子分析、期权校验与报告生成
  • 返回 run card、导出文件、工具 trace 与 caveat，供下一轮会话使用

交易研究 Swarm 团队

预设研究团队
多个专职 worker 并行协作同一研究问题。预设团队包括 investment committee、quant desk、risk review、macro、crypto、catalyst 等 — 各角色有明确分工、证据要求与汇总步骤。
$ vibe-trading --swarm-run investment_committee workers: macro, quant, risk, catalyst report saved with evidence, metrics, and caveats
单 Agent 与团队模式
简单问题路由到单 Agent 工具批处理；复杂问题启动团队，worker 多空辩论后由 lead 合成报告。这与我在 NL2BP 中探索的多 Agent 编排模式一脉相承，但应用场景从 UML 蓝图生成转向金融研究。

我使用的核心能力

Agent harness
持久记忆、会话检索、可编辑 skills、上下文压缩与工具批处理研究运行。
回测引擎
覆盖股票、 crypto、期货、外汇、组合与期权共七类引擎。
Shadow account
解析券商流水、抽取隐含规则、反事实回测与审计报告。
$ vibe-trading run -p "Backtest BTC-USDT 20/50 MA for 2024" route: crypto data -> strategy -> backtest -> run card return +18.6% max drawdown -7.4%

相关 Agent 工具链

AI 开发工具： 日常使用 Cursor、Claude Code、Codex、OpenCode 做 harness 工程、skill 编写与可复现 Agent 运行 — 不仅是 prompt，还包括工具接线、trace 与评测闭环。

Hermes Agent： 深入研究 NousResearch/hermes-agent 的 gateway/会话路由、消息适配与模型切换架构 — 并应用于 KithAgent 本地 Agent 基础设施。
