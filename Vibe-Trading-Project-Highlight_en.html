Vibe-Trading

Open-Source Finance Research Agent with Multi-Agent Swarm Teams
Wiki: vibetrading.wiki | GitHub: HKUDS/Vibe-Trading | PyPI: vibe-trading-ai
Summary. Vibe-Trading turns natural-language market questions into runnable research: route skills and data sources, ground on live market data or broker journals, run backtests and factor analysis, and deliver reproducible run cards with evidence, metrics, and caveats. My hands-on work focuses on orchestrating preset swarm teams, designing agent harness workflows, and connecting this finance agent stack to broader agent-tooling research (Cursor, Codex, Hermes Agent).

Research Loop

Route → Ground
  • Select skills, data sources, tools, and swarm teams from the user prompt
  • Fetch equities, crypto, futures, forex, documents, URLs, or broker journals at runtime
Test → Deliver
  • Run backtests, factor analysis, options checks, and validation
  • Return run cards, exports, tool traces, and caveats for the next session

Swarm Teams for Trading Research

Preset research teams
Parallel specialist workers collaborate on a single research question. Preset teams include investment committee, quant desk, risk review, macro, crypto, and catalyst analysts — each with a defined role, evidence requirements, and synthesis step.
$ vibe-trading --swarm-run investment_committee workers: macro, quant, risk, catalyst report saved with evidence, metrics, and caveats
Single-agent and team modes
Simple prompts route to a single research agent with tool-batched runs; complex questions spawn a team where workers debate bull/bear views before a lead synthesizes the final report. This mirrors the multi-agent orchestration patterns I previously explored in NL2BP, applied to finance research instead of UML blueprint generation.

Capabilities I Work With

Agent harness
Persistent memory, session search, editable skills, context compression, and tool-batched research runs.
Backtesting
Seven engines across equities, crypto, futures, forex, composites, and options portfolios.
Shadow account
Parse broker journals, extract implicit rules, run counterfactual backtests, and render audit reports.
$ vibe-trading run -p "Backtest BTC-USDT 20/50 MA for 2024" route: crypto data -> strategy -> backtest -> run card return +18.6% max drawdown -7.4%
