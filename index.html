Being-H0.5 — VLA reproduction & experiments

HKU MSc project · 2025 – 2026 · advised by Prof. Taku Komura

Being-H0.5 is prior work from the literature, not something I designed with Prof. Komura. I read the paper, treated it as an important reference, and spent this project trying to reproduce and extend their pipeline on my own hardware.

The goal was practical: get the full vision-language-action stack running — deployment, inference, evaluation, and from-scratch post-training — so I could compare results honestly instead of trusting checkpoints at face value.

What I actually did:

  • Set up the repo, a ZeroMQ inference server, and rollout evaluation on LIBERO and RoboCasa (MuJoCo with headless EGL rendering).
  • Ran from-base fine-tuning on 4 GPUs with FSDP — InternVL3.5-4B + Qwen3-4B mixture-of-transformers, flow matching, MPG — and wrote launch scripts plus runbooks so experiments could be repeated without guesswork.
  • Ported the training code to NVIDIA Blackwell (sm_120): PyTorch 2.8 + cu128, and a handful of fixes for attention, gradient checkpointing, and distributed setup that were blocking runs on the new cards.
  • Ran a controlled comparison that stuck with me: the official 2B checkpoint scored 95–98.6% on LIBERO spatial, while my 4B model trained from base for 6k steps only reached 37.8% (500 episodes). Scaling the backbone without the original Being-H pre-training was not enough.
  • Built a small ablation on an alternative action head (Gemma-4-E2B with cross-attention, flow matching, LoRA) and saw roughly 17% lower L1 floor than a simpler last-token MLP baseline — early signal, not a finished method.

Stack: PyTorch, FSDP, DeepSpeed, Transformers, LIBERO, RoboCasa, ZeroMQ.

Skillios (ItsMyGoal) — goal-planning iOS app

Personal project · 2025 – 2026

I wanted a goal planner that felt like a game rather than a spreadsheet. The iOS client is SwiftUI + SwiftData: skill trees, quests, XP, todos, and daily routines. When you set a goal, an on-device agent breaks it into a structured plan and keeps the tree in sync as you edit tasks.

On the backend I used AWS CDK to stand up VPC, ALB, ECS Fargate, RDS PostgreSQL, and Secrets Manager. FastAPI handles sync, an LLM proxy, and LangChain agent routes. The hard part was keeping the JSON plan format stable between the phone and the server so the agent tools did not drift.

Stack: Swift, SwiftUI, SwiftData, FastAPI, SQLAlchemy, AWS CDK, LangChain.

KithAgent — local memory for coding agents

Personal project · 2025 – 2026

I use Cursor and similar tools daily and got tired of re-explaining context. KithAgent watches folders I choose, uses an LLM to triage files (keep, summarize later, or skip), and builds a local memory store in SQLite. When I am idle it summarizes the important stuff in the background.

Retrieval mixes exact file lookup with RAG. There is a small API so other agents can pull context into a session. The UI is Electron + React; the worker is a Python daemon with scheduled jobs and pytest coverage on the integration paths I care about.

Stack: Python, FastAPI, SQLite, Electron, React, TypeScript.
